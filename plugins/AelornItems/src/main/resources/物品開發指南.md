# MMOItems 1.8 武器與穿戴需求指南

本版採用原創、資料驅動的 ARPG 裝備規格。修改 YAML 後執行 `/mi reload`，
不用重新編譯插件。

## 物品需求

```yaml
requirements:
  combat-level: 35
  classes: [Arcanist]
  skills:
    intelligence: 32
    agility: 10
  quests: [ember_warning]
```

- `combat-level`：戰鬥等級下限。
- `classes`：可列出多個職業，符合其中一個即可。
- `skills`：支援 `strength`、`dexterity`、`intelligence`、`defence`、`agility`。
- `quests`：由 RPGCore 讀取角色任務進度並執行限制。
- 權限 `mmoitems.bypass.requirements` 可略過 MMOItems 的等級、職業與能力需求。

## 大型特性

大型特性是固定玩法，不屬於隨機數值詞條。實際效果應由能力或戰鬥模組依 ID 實作。

```yaml
major-identification:
  id: starfire_reserve
  name: '&b星火儲能'
  description:
    - '連續施放不同能力時累積星火，降低下一次技能消耗。'
```

## 數值格式

```yaml
main-attack-damage:
  base: 8.0
  scale: 0.35
  spread: 0.10
main-attack-damage-percent: { base: 6.0, scale: 0.12 }
```

- `base`：一級基礎值。
- `scale`：每個物品等級增加量。
- `spread`：隨機浮動比例；`0.10` 代表上下約 10%。
- 原始傷害與百分比傷害分開計算，不要將百分比寫成 `0.05`；5% 請寫 `5`。

## 詞條限制

```yaml
deadeye:
  weight: 30
  prefix: '&e鷹準'
  group: precision
  item-types: [BOW, GREATBOW, CROSSBOW, MUSKET]
  excluded-item-types: []
  tiers: [RARE, EPIC, LEGENDARY, VAST, MYTHIC]
  min-level: 10
  max-level: 100
  major: false
  stats:
    projectile-damage: { base: 4.0, scale: 0.22 }
```

- `weight`：同一候選池的相對抽取權重。
- `group`：同組詞條每件物品最多一個，避免同義能力重複。
- `item-types`：空白代表不限；填寫後只會出現在指定類型。
- `tiers`：空白代表不限。
- `major: true`：每件物品最多抽到一個核心詞條。

## 七個正式品質

`COMMON` 凡品、`UNCOMMON` 優良、`RARE` 稀有、`EPIC` 史詩、
`LEGENDARY` 傳說、`VAST` 浩瀚、`MYTHIC` 神話。

`STARTER` 僅供新人流程與測試，不進入隨機掉落池。

## 常用屬性族

- 攻擊：`main-attack-damage`、`spell-damage`、`attack-speed`、`range`、
  `critical-strike-chance`、`critical-strike-power`、各類穿透。
- 元素：大地、雷霆、流水、烈焰、疾風，以及冰霜、暗影、聖光、奧術、自然。
- 生存：生命、防禦、元素抗性、格擋、閃避、招架、荊棘、投射反射。
- 資源：魔力、耐力、生命／魔力竊取、四技能消耗、冷卻縮減。
- 探索：移動、衝刺、跳躍、經驗、掉寶數量、掉寶品質、採集。

完整可編輯清單可在 `/mi editor` 的屬性頁查看；名稱、單位與安全上限都來自同一份屬性字典。
